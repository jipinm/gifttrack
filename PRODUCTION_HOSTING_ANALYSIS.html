Production Hosting & Cost Analysis

This report provides the recommended server configuration and estimated costs for the GiftTrack production environment, based on the current PHP/MariaDB API and Expo mobile codebase.

1. Technical Requirements

  • Backend (PHP API): High memory requirement (512MB+) for PhpSpreadsheet Excel imports.
  • Database (MariaDB): Optimized schema; ~50,000 customers require ~150MB storage.
  • Authentication: Stateless JWT, allowing for efficient horizontal scaling.
  • Concurrency: Optimized for simultaneous mobile app requests and bulk uploads.

Import Performance Thresholds

The import.php logic performs a mobile number duplicate check for every row. As the database grows, the import speed will drop:

  • < 10k rows: 5-15 seconds (Safe for standard PHP).
  • 10k - 50k rows: 1-3 minutes (Requires max_execution_time adjustment).
  • 50k+ rows: Risk of PHP memory exhaustion. Suggest switching from PhpSpreadsheet to a Streamed CSV Parser for these scales.
